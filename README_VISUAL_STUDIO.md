# Visual Studio launch

In Visual Studio 2026 with the **Python development** workload installed, open `SteganographyLab.slnx`. The startup script is `steganography.py`.

Select a Python environment with Pillow installed (`python -m pip install -r requirements.txt`). Running with the IDE will create the `output/` directory next to the script. Alternatively, use the terminal command from the main README.
